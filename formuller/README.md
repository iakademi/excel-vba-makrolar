# Formüller

Modern Excel formülleri için örnek odaklı kısa kılavuzlar. Tüm örneklerde Türkçe Excel'de ayırıcı olarak noktalı virgül (`;`) kullanılır; İngilizce arayüzde virgül (`,`) kullanın. Fonksiyon adları da Türkçe sürümde farklıdır (örneğin `XLOOKUP` yerine `ÇAPRAZARA`); kılavuzlarda İngilizce adlar tercih edilmiş, Türkçe karşılıkları tabloda verilmiştir.

| Kılavuz | Konu |
| --- | --- |
| [XLOOKUP.md](XLOOKUP.md) | DÜŞEYARA'nın modern ve esnek alternatifi |
| [FILTER.md](FILTER.md) | Koşula uyan satırları dinamik olarak süzme |
| [LET.md](LET.md) | Formül içinde adlandırılmış değişkenler |
| [LAMBDA.md](LAMBDA.md) | Kendi yeniden kullanılabilir fonksiyonlarınızı yazma |
| [dinamik-diziler.md](dinamik-diziler.md) | Taşan (spill) sonuçlar ve dizi fonksiyonları |

## Sürüm Gereksinimi

Bu fonksiyonlar Microsoft 365 ve Excel 2021 ve sonrasında bulunur. Daha eski sürümlerde çalışmaz.
